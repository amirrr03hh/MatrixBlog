## ✨ Features

- **92 posts** – each a deep dive into the Matrix, NPCs, AI, time, death, and awakening.
- **Expandable cards** – click any post header to read the full content.
- **🔍 Search** – instant filtering with **in‑content highlighting** of matches.
- **🏷️ Tag filtering** – click any tag to see related posts.
- **📌 Bookmarks** – star your favorite posts; filter to see only bookmarks.
- **🌍 Translation** – translate any post into 10+ languages (including Farsi with RTL support). The widget shows your current language and auto‑translates when you expand a post if your preferred language isn’t English.
- **🌙 Dark mode** – toggle with a single click; preference saved in your browser.
- **🔗 Copy post link** – share a direct link to any post.
- **📖 Related posts** – automatically suggested based on shared tags.
- **📜 Pagination** – load 20 posts at a time for smooth performance.
- **💾 Persistent state** – your open posts, filters, search, bookmarks, and even scroll position are remembered across page refreshes.
- **📱 Responsive** – works beautifully on desktop, tablet, and mobile.
- **♿ Accessible** – ARIA labels, keyboard shortcuts (`/` to search, `Esc` to clear), and skip‑to‑content link.

---

## 🚀 How to Use

1. **Download** the `index.html` file.
2. **Open** it in any modern browser – no server required.
3. Start reading, searching, and bookmarking.

---

## 🛠️ Tech Stack

- Pure **HTML5**, **CSS3**, and **Vanilla JavaScript**
- No external libraries or frameworks – everything is self‑contained
- LocalStorage for persistent state
- MyMemory & LibreTranslate APIs for translation (with fallback)

---

## 📦 Deployment

You can host this archive anywhere that serves static files. The easiest way is **GitHub Pages**:

1. Push the `index.html` file to a GitHub repository.
2. Go to **Settings > Pages** and set the source to the root of the `main` branch.
3. Your site will be live at `https://amirrr03hh.github.io/MatrixBlog/`.
